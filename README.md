# CardFlow 拷卡助手

CardFlow 是一款面向摄影、影视拍摄及现场数据管理的 Windows 素材拷贝工具。支持图片、相机 RAW、专业视频、音频及关联文件的识别、筛选、分类复制和完整性校验。

## 系统要求

- Windows 10 1803 或更高版本
- Windows 11
- 仅支持 64 位系统
- 建议至少保留 500 MB 安装空间
- 执行拷贝任务时，目标磁盘需要具备充足的可用容量

软件不要求另外安装 Node.js、Rust、FFmpeg 或 ExifTool。

## 安装方法

1. 下载 `CardFlow 拷卡助手_1.3.3_x64-setup.exe`。
2. 双击运行安装程序。
3. 根据安装向导选择安装位置及安装范围。
4. 安装完成后，可以通过桌面快捷方式或开始菜单启动 CardFlow。

## 基本使用流程

CardFlow 的操作分为三个步骤：

1. 选择素材
2. 设置拷贝规则
3. 选择目标并执行

### 第一步：选择素材

1. 将 SD 卡、CFexpress 卡、移动硬盘或读卡器连接到电脑。
2. 在顶部磁盘列表中选择素材来源。
3. 也可以点击“选择来源”，手动选择普通文件夹。
4. 等待软件完成轻量素材清点。
5. 使用素材类型、文件格式、拍摄日期等条件筛选素材。
6. 在素材列表中勾选需要复制的文件。
7. 点击“加入素材篮”。

支持的主要素材类型包括：

- 常见图片：JPEG、PNG、TIFF、HEIC 等
- 相机 RAW：NEF、NRW、ARW、CR2、CR3、DNG、RAF、ORF、RW2 等
- 专业视频：MOV、MP4、MXF、MTS、M2TS、R3D、BRAW、ARI、ARX、CRM、NEV 等
- 音频：WAV、BWF、MP3、AAC、M4A、FLAC、AIFF 等
- 关联文件：XMP、XML、THM、LRV 及相关代理文件

CardFlow 不会向素材卡写入文件，也不会删除、移动或格式化来源素材。

### 多张卡的素材

切换磁盘时，软件会询问是否清空素材篮：

- 选择清空：移除上一张卡加入的素材。
- 选择保留：上一张卡的素材继续保留，可以继续加入新磁盘中的素材。

使用多张卡时，建议为每张卡设置不同的机位和卡号，例如：

- A机 / A001
- B机 / B001
- 无人机 / D001

这样可以减少多机位素材混淆。

### 第二步：设置拷贝规则

#### 工作流预设

工作流预设可以保存常用的完整拷贝设置，包括：

- 拷贝模式
- 校验算法
- 项目名称
- 机位和卡号
- 目录结构
- 目录名称
- 分类层级
- 文件命名规则
- 默认目标位置

载入预设后仍可以临时调整。本次修改不会改变已经加入队列的任务。

#### 拷贝模式

**单盘快速拷贝**

不进行文件校验，适合临时快速转存。速度较快，但不提供内容一致性验证。

**单盘安全拷贝**

复制到一个目标位置，并使用 MD5 或 XXH64 校验来源文件和目标文件是否一致。

**双盘备份**

将素材依次写入两个目标位置，并分别进行完整性校验，适合现场工作盘与备份盘同时留存。

#### 校验算法

**MD5**

兼容性广，便于与其他软件或交付清单核对。

**XXH64**

校验速度通常更快，适合大容量素材的快速完整性检查。

关闭校验时，软件只确认文件复制流程完成，不验证来源与目标内容是否完全一致。

#### 目录结构

可选择：

- 保留原目录
- 扁平复制
- 按分类规则重组

可以使用项目名、拍摄日期、机位、卡号、媒体类型或文件后缀等字段组合目录名称。

实时预览会根据素材篮中的真实素材，展示预计生成的目录结构。

#### 文件重命名

默认保留原文件名。

开启文件重命名后，可以组合使用：

- 项目名称
- 拍摄日期
- 拍摄时间
- 机位
- 卡号
- 原文件名
- 媒体类型
- 流水序号
- 自定义文字

软件会实时展示最终文件名。原始扩展名会被保留。

### 第三步：目标与执行

1. 选择工作盘或目标文件夹。
2. 双盘备份模式需要选择两个不同的目标位置。
3. 检查目标磁盘的可用容量和写入状态。
4. 点击“添加到任务队列”。
5. 可以继续返回前面的步骤，创建更多任务。
6. 在队列中选择需要执行的任务。
7. 点击“开始全部任务”或“开始选定任务”。

任务按照队列顺序执行。

## 任务控制

### 暂停与继续

复制过程中可以暂停队列。暂停后，点击“继续拷贝”即可恢复。

软件会保留已完成文件和当前任务状态，已经成功校验的文件不会重复复制。

### 停止任务

停止正在执行的任务时：

- 已成功复制的文件会保留。
- 未完成的临时文件会被清理。
- 任务记录和当前报告会被保存。
- 之后可以将任务放回队列，继续处理未完成项目。

### 关闭软件

如果没有正在执行的任务，关闭时会显示普通确认提示。

如果存在传输任务，选择“暂停并关闭”后，软件会先安全暂停任务、保存进度和报告，然后退出。下次启动后可以继续任务。

请避免在复制过程中直接断开读卡器或目标磁盘。

## 拷贝报告

任务完成、暂停、取消或失败时，CardFlow 会生成报告。

报告包括：

- 全部文件数
- 成功数量
- 已校验数量
- 快速复制数量
- 已存在且内容一致
- 跳过数量
- 失败数量
- 取消数量
- 各目标位置的执行结果
- 文件错误原因
- 开始时间、耗时及任务状态

启用校验时，目标位置还会生成相应的校验清单。

可以在任务或历史记录上点击右键，选择“在资源管理器中显示”，打开已经复制的目标位置。

## 历史任务

历史任务支持以下右键操作：

- 放回队列
- 删除
- 在资源管理器中显示
- 清空历史记录

将失败、部分成功或取消任务放回队列时，CardFlow 会建立一个新的活动任务。原历史记录继续保留，已经成功的文件不会重复复制。

删除历史记录不会删除目标磁盘上的素材文件。

## 缩略图说明

CardFlow 优先调用 Windows 提供的缩略图和预览能力。

对于部分相机 RAW 或专业摄影机格式：

- 如果 Windows 可以提供缩略图，软件会直接显示。
- RAW 文件可能使用文件内嵌预览。
- 专业原片存在代理文件时，可以使用代理缩略图。
- 无法生成预览时，会显示相应格式图标，但文件仍能被识别、选择和复制。

缩略图仅用于浏览，不影响原始素材内容。

## 使用建议

- 正式项目建议至少保留两个独立副本。
- 重要素材建议使用 MD5 或 XXH64 校验。
- 开始任务前确认目标盘容量充足。
- 拷贝完成并确认报告无误前，不要格式化内存卡。
- 双盘备份最好使用两块独立物理磁盘。
- 不建议将两个目标位置设置在同一块物理硬盘的不同分区。
- 建议对重要项目额外保留异地备份。

## 卸载方法

可以通过以下位置卸载：

`Windows 设置 → 应用 → 已安装的应用 → CardFlow 拷卡助手`

卸载程序不会主动删除已经复制的素材文件。软件设置、历史记录和缩略图缓存可能继续保留在用户数据目录中。
